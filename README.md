# Invitación digital — XV años de Lizbeth Sarahí Ruiz Jurado

La invitación usa los tres paneles de la imagen de referencia como arte de cada hoja y agrega controles flotantes para avanzar, retroceder, elegir página y deslizar en celular.

## Vista previa local
1. Descomprime el ZIP.
2. Abre la carpeta en Visual Studio Code.
3. Abre `index.html`.
4. Pulsa **Go Live** en la barra inferior, o clic derecho en `index.html` → **Open with Live Server**.

También puedes abrir `index.html` directamente con Chrome o Edge.

## Publicar después en GitHub Pages
Sube todos los archivos y la carpeta `assets` a la raíz de tu repositorio. Luego ve a Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
